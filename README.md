# savED: scroll without triggers

savED is a Chrome extension that uses AI to blur diet culture content on Instagram, TikTok and YouTube, so teens in eating disorder recovery can scroll without getting triggered.

**Track:** AI + Health · **Team:** Hannah Chen, Kavya Ghosh, Devika Jain

## What's in this repo
- `notebooks/model_training.ipynb`: training, baselines and all results
- `Main Extension/`: the Chrome extension and local server (setup: [SETUP.md](Main%20Extension/SETUP.md))
- `*_paraphrased*.csv`: our labeled, paraphrased training and test posts (no original captions)
- `savED real world testing - Prompt 1.csv` / `Prompt 2.csv`: live test results on 150 posts

*This project is a prototype and is not medical advice.*
